新增功能一覽

📊

AHP 複合安全指數

14 項安全準則以 Analytic Hierarchy Process 加權，輸出 1-5 分五級安全等級。分為 static（地形only，用於規劃分區）和 composite（含即時天氣，用於動態評估）。

🗺️

空間安全地圖

逐網格計算 AHP 指數，輸出 GeoJSON FeatureCollection。每個 cell 帶有 static_score / class / colour，可直接渲染分級色塊地圖。

🌐

三區域 AHP 權重

台灣、日本、印尼各有獨立 pairwise matrix 和評分表，反映不同氣候/地質/生態條件下的危害優先級。一致性比率全部 < 0.10。

🔗

GIS 地形自動取得

backend 設 use_gis_terrain=true + lon/lat，自動從 gis-service PostGIS 取得真實 DEM 地形參數，取代手動預設值。

⚡

多危害評估引擎

從單一崩塌擴展為四種危害：崩塌/土石流、溪流暴漲、倒木/落枝、熱危害。safety_level 取最嚴重者驅動通知。

📋

AHP 權重審計

公開端點暴露 AHP 權重、一致性比率、評分詞彙、區域比較基準。滿足專家審查與可追溯性要求。

📧

通知系統升級

Email + LINE 通知模板更新為多危害安全語言，包含複合指數作為規劃參考。不稀釋官方警報觸發。

🏗️

雙軌風險計算

compute-static-risk 同時計算舊版 0-100 分（相容既有前端）和 AHP 1-5 五級（新框架），無縫遷移。

新增 API 端點

gis-service 空間安全分析
  • GET /api/v1/{project_id}/disaster/safety-index-map
    逐網格 AHP 安全指數 → GeoJSON。支援 static (地形only) / composite (含天氣) 模式。bbox 空間篩選、max_features 限制。
  • GET /api/v1/{project_id}/disaster/terrain-profile
    座標查詢最近網格地形參數 (slope/aspect/geomorphon/twi/elevation/ndvi/canopy_height/flow_accumulation)。供 backend 自動取得。
  • GET /api/v1/{project_id}/disaster/ahp-weights
    AHP 權重審計: groups/criteria/consistency_ratios/rationale/rainfall_reference/available_regions。
  • POST /api/v1/{project_id}/disaster/compute-static-risk UPGRADED
    新增 region 參數，雙軌計算: 舊版 0-100 + AHP 1-5 五級。寫入 ahp_static_score / ahp_static_class 欄位。
backend 多危害安全評估
  • GET /weather/landslide-risk UPGRADED
    新增參數: region, soil_type, accessibility_minutes, wildlife, abnormal_trees, use_gis_terrain, lon, lat, wind_speed_ms, temperature_c, humidity_pct, canopy_height_m, ndvi, aspect_deg, geomorphon, elevation_m。回傳多危害評估 + 複合指數 + terrain_source。
  • GET /weather/safety-criteria NEW
    AHP 權重透明化端點: 每個區域的 group/global 權重、一致性比率、評分詞彙、區域比較基準。

設計原則

  • 複合指數不稀釋警報觸發 — AHP composite index 僅作為規劃參考，alert gating 仍由官方 SWCB/JMA 門檻值驅動。測試 test_composite_index_does_not_soften_a_threshold_breach 確保此分離。
  • Static score 不含天氣 — 地形only 分數可用於長期規劃分區，不受天氣變化影響。測試 test_static_score_excludes_weather 確保。
  • 雙軌相容 — 舊版 0-100 分與 AHP 1-5 五級並存，既有前端不受影響，新前端可逐步遷移。
  • AHP 可審計 — 權重、一致性比率、評分詞彙全部透過 API 公開，專家可 review 並追溯。
